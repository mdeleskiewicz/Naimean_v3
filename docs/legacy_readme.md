## 🏛️ Naimean AI Core Subsystem ('/aicore')
*Recovered from Historical Deployment Snapshots*

This directory contains the core service architecture, database migrations, configurations, and user interface modules for the **Naimean AI Core Control Console (`/aicore`)** embedded within the `Naimean_v3` ecosystem.

The subsystem orchestrates an **Ensemble Jury Parallel Processing Engine** that leverages your licensed flagship models (**OpenAI GPT-4o**, **Google Gemini Pro**, and **OpenAI GPT-4-Turbo**) to generate, cross-examine, audit, and format high-acuity medication profiles into a strict, copy-paste ready format.

### The User Experience (UX)
1. **State A: The Inquiry (Input):** User provides a prompt.
2. **State B: The Jury Deliberation (Processing):** Three independent LLM "Jurors" generate drafts; a "Lead Auditor" cross-references them to find discrepancies and reach consensus.
3. **State C: The Verdict (Output):** The engine outputs a sanitized, Markdown-formatted profile. Users can preview "Jury Notes" to see how consensus was reached.
4. **State D: The Record (History):** Successful outputs are stored in a database for audit trails.
